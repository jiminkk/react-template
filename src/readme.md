Snake Game

Grid matrix with a certain size 20x20
Snake player at a initial position and direction
Target at initial position

Snake movements:

- snake is constantly moving one step into the current direction
- we can set direction using arrow keys
- when snake is in same position as current target, grow snake length by 1

Food target:

- start at initial position
- once consumed, set to random position

Game over:

- snake runs into wall
- snake runs into itself
